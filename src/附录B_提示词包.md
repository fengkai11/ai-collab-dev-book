# 附录 B：提示词包

## 1. 压缩模糊需求

```text
我有一个模糊产品想法：
【粘贴想法】

请不要生成完整 PRD，也不要写技术架构。
请输出：
1. 一句话定位；
2. 目标用户；
3. 用户核心问题；
4. 3 个候选最小闭环；
5. 推荐第一切片；
6. 本阶段不应展开的功能；
7. 待确认项。
```

## 2. 生成一页纸产品合同

```text
请基于下面想法生成一页纸产品合同。
字段：功能名称、目标用户、核心问题、本版闭环、成功标准、本版做、本版不做、待确认项。
要求成功标准可验收，不确定内容放待确认项，不写技术架构。
【粘贴想法】
```

## 3. 审查产品合同

```text
请审查下面产品合同。
检查：目标是否过大、用户是否清楚、成功标准是否可验收、不做项是否明确、是否有脑补风险。
按“问题 → 风险 → 修改建议”输出。
【粘贴合同】
```

## 4. 输出页面预览

```text
基于下面产品合同，只输出第一切片页面预览。
不要写代码、数据库、接口、后端。
输出页面列表、页面目标、区块、按钮、点击结果、空状态、加载态、错误态、待确认项。
【粘贴合同】
```

## 5. 识别最小闭环

```text
下面是完整想法：
【粘贴想法】

请不要展开完整系统。输出 5 个候选闭环，每个包含起点、终点、用户价值、是否可 mock、复杂度、是否适合第一切片。最后推荐一个。
```

## 6. 拆第一切片

```text
请把下面第一切片拆成可执行定义。
输出：一句话定义、起点、终点、页面范围、用户路径、数据策略、做什么、不做什么、验收标准。
不要写代码和接口。
【粘贴切片】
```

## 7. 限制 GPT 不发散

```text
请停止扩展完整系统。现在只围绕以下切片工作：
【切片名称】

禁止展开：
1.
2.
3.

重要但不属于本轮的内容，请放到“后续切片建议”，不要写详细方案。
```

## 8. 生成施工任务单

```text
请把下面材料整理成 Claude Code / Codex 可执行施工任务单。
必须包含目标、输入、输出、功能范围、数据策略、不做项、技术约束、验收标准、完成后汇报格式。
只做一个切片，不要新增功能。
【粘贴材料】
```

## 9. 交给 coding agent

```text
你是 coding agent。请严格按施工任务单执行，不要自行扩展，不要改无关文件。
如果需求不明确，列为待确认项。
完成后回复：完成内容、变更文件清单、运行方式、验收对照、已知问题、是否超范围改动。
【粘贴施工单】
```

## 10. 生成验收清单

```text
请基于第一切片定义生成手工验收清单。
分为正常流程、异常流程、边界情况、越界检查。
每条包含操作步骤和期望结果。
不要写自动化测试代码。
【粘贴切片定义】
```

## 11. 判断返工类型

```text
下面是验收失败项。请判断每项属于产品返工、实现返工、需求未定义、越界实现或本版不要求。
输出：问题、判断、理由、建议下一步。
【粘贴问题】
```

## 12. 写返工单

```text
请把下面问题整理成 coding agent 可执行返工单。
每个问题包含复现步骤、当前结果、期望结果、问题类型、修改范围、返工后复验项。
不要新增功能。
【粘贴问题清单】
```

## 13. 做项目复盘

```text
请基于下面开发记录做复盘。
分析需求偏航、实现偏航、有效提示词、无效提示词、验收是否充分、下一切片如何改进。
【粘贴记录】
```

```text
{输入}
```

## B.6 生成施工单

```text

2. 页面预览：{粘贴}
3. 切片边界：{粘贴}
```
