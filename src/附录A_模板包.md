# v0.3 扩写：完整模板使用说明

以下模板可以直接复制到项目文件夹中使用。建议每个项目不要一次性填完所有模板，而是随着切片推进逐个使用。

## A.1 产品想法记录卡

### 使用场景

当你只有一个模糊想法时使用。目标是先记录，不急着展开。

```markdown
# 产品想法记录卡

## 1. 我想做什么

## 2. 给谁用

## 3. 用户现在有什么问题

## 4. 如果做成，用户会获得什么结果

## 5. 这个想法最容易膨胀成哪些功能
1.
2.
3.
4.
5.

## 6. 我现在最想先验证的一件事
```
