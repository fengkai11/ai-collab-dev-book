# AI 协同开发：切片式开发训练手册

一本写给非专业程序员和 AI 开发新手的实战手册。

你不需要先成为全栈工程师，也不需要一开始就设计完整系统。这本书训练的是另一种更适合 AI 时代的能力：把模糊想法压缩成清晰目标，把大项目拆成可执行的小切片，再用页面预览、施工任务单、验收清单和返工单，把 GPT、Claude Code、Codex、Cursor 等工具真正管起来。

## 这本书适合谁

- 有产品想法，但缺少系统开发经验的人
- 正在用 AI 写代码，却经常遇到功能发散、返工失控的人
- 想把 GPT、Claude Code、Codex、Cursor 用成稳定工作流的人
- 希望从“让 AI 多写一点”升级到“让 AI 在正确范围内写”的人

## 你会学到什么

本书围绕一条可执行的 AI 协同开发路线展开：

```text
产品合同 -> 页面预览 -> 最小闭环 -> 切片任务 -> 施工单 -> 验收 -> 返工 -> 复盘
```

读完并完成练习后，你应该能做到：

- 把一句模糊需求压缩成一页纸产品合同
- 找到一个产品里的最小可用闭环
- 拆出 AI 能稳定执行的第一切片
- 写出给 GPT、Claude Code、Codex 使用的清晰任务单
- 用验收清单判断 AI 产出是否真的可用
- 区分“产品设计需要返工”还是“代码实现需要返工”
- 建立自己的个人 AI 协同开发工作流
